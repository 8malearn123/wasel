- **المرجع:** نموذج «واصل Wasel — النموذج التفاعلي»، 86 شاشة لستة أدوار.
- **الفرع:** `claude/design-refresh`، من `claude/frontend-regression-fixes` عند `00fb089`.
- **القاعدة:** واجهة فقط. لا تغيير في المسارات، أو منطق النظام، أو الصلاحيات، أو الباقات، أو قاعدة البيانات، أو الـ API.

## 2) ما سيُنفّذ (واجهة فقط، بالترتيب، مع اختبار بعد كل مرحلة)

**المرحلة A — الأساس العام** (الأقل خطرًا والأوسع أثرًا):
1. توكنات الألوان والزوايا والظلال بقيم النموذج، وإضافة ألوان دلالية: معلومة، وخطر، وتحذير.
2. الشريط الجانبي: المظهر الجديد بمجموعات معنونة، **بنفس العناصر والروابط وشروط الظهور**.
3. رأس الصفحة: العنوان والوصف، والبحث، والإشعارات. **يبقى** محدد الفرع وزر اللغة وزر المظهر.
4. مكوّنات عامة: بطاقة مؤشر (KPI)، ورأس قسم، وشارة حالة.

**المرحلة B — لوحة التحكم:**
- المظهر الجديد.
- إضافات تُحسب من البيانات الحالية:
  - مبدّل الفترة (7 أيام / 30 يومًا / 12 شهرًا) مع مقارنة بالفترة السابقة؛
  - توزيع المبيعات حسب الفئة؛
  - تركيبة المخزون؛
  - اختصارات سريعة؛
  - تقدّم الهدف الشهري من أهداف الموارد البشرية الحالية؛
  - المتجر الإلكتروني كقناة في أداء الفروع.

**المرحلة C — صفحات المدير:** إعادة تصميم كل صفحة بنفس وظائفها، مع إضافات لا تحتاج Backend:

| الصفحة | الإضافات |
|---|---|
| نقطة البيع | شرائح الفئات، واختصار F2 للبحث |
| المنتجات | عرض شبكة أو قائمة، وهامش الربح، ومبيعات آخر 30 يومًا |
| الصيانة | لوحة Kanban بحالات الصيانة الحالية نفسها |
| المخزون | خريطة تغطية المخزون حسب الفئة والفرع |
| الموردون | اقتراحات إعادة الطلب (عرض فقط) |
| التقارير | ساعات الذروة، وربحية الفئات |
| العملاء والتسويق | المظهر الجديد |
| الشحن، الإعدادات، الاشتراك | المظهر الجديد |

**المرحلة D — المتجر (العميل):**
- المظهر الجديد.
- إضافات لا تحتاج Backend:
  - شريط الفئات، وبحث في الرأس؛
  - شريط تنقّل سفلي على الجوال؛
  - فلاتر العلامة التجارية والسعر؛
  - عدّاد الكمية، ومنتجات مشابهة؛
  - تبويبات «الحالية / السابقة» في طلباتي؛
  - نسخ رقم التتبع.

## 3) ما لن يُنفّذ دون قرارك (يغيّر سلوك النظام)

- **نقل عناصر القائمة:** الفروع والمستخدمون والجملة والاستوديو إلى عناصر مستقلة، بدل أماكنها الحالية.
- **العناصر المقفولة:** إظهارها بقفل بدل إخفائها.
- **عناصر غابت عن النموذج:** أكواد التحقق، وأجهزة البصمة، وسياسة العمل، والدعم الفني، ومحدد الفرع وزر اللغة. **ستبقى كما هي.**
- **الولاء:** النموذج بثلاث مستويات، والحالي أربع.
- **الإغلاق:** النموذج لكل وردية، والحالي لكل يوم.
- **الفروع:** النموذج ينشئ الفرع مباشرة، والحالي عبر طلب ومراجعة ودفع.
- **الأدوار:** النموذج يستخدم مالك / كاشير / محاسب / موظف، بدل الأدوار الحالية والمخصصة.
- **المنتجات:** النموذج يدمج الأجهزة والإكسسوارات وقطع الصيانة في كتالوج واحد. الحالي ثلاثة جداول.
- **ضريبة المتجر:** سلة المتجر الحالية تضيف الضريبة فوق السعر، بينما نقطة البيع والنموذج يعتبران السعر شاملًا. **تناقض قائم** يحتاج قرارك.

## 4) ما يحتاج Backend (جاهز في التقرير، ولن يُنفَّذ)

| المجال | المتطلبات |
|---|---|
| البوابات الجديدة | الموظف، والمحاسب، والمورد، وحساب عميل المتجر: أدوار ومصادقة وجداول جديدة |
| الكاشير | الورديات مع الرصيد الافتتاحي وحركات الدرج، والمرتجعات وإشعارات الدائن، وموافقة الخصم والاسترداد |
| المحاسبة | المصروفات، وفواتير الشراء ومدفوعات الموردين، وذمم العملاء، وكشوف البنك والتسويات، والفترات المحاسبية، ودفتر الأستاذ |
| التكاملات | تمارا وتابي، وجهاز مدى، وZATCA المرحلة الثانية، وإرسال واتساب، وواجهات شركات الشحن، وبوابة دفع الاشتراك |
| أعمدة جديدة | `sales.customer_id` و`status` و`shift_id`، و`online_orders.assignee`، والاستلام الجزئي في أوامر الشراء، و`parent_id` للتصنيفات، والتقييمات، والسعر قبل الخصم، ووصف المنتج ومواصفاته |
